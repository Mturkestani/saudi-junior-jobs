الهدف النهائي

خدمة تجمع وظايف التقنية للخريجين وبرامج تطوير الخريجين في السعودية كل يوم، وتشيل اللي يطلب خبرة، وتنبّه المشتركين بالجديد على تيليجرام، وفيها صفحة ويب عامة.

بعد 4 أسابيع يكون عندك:

  • صفحة ويب عامة برابط حقيقي، تتحدث كل يوم.
  • بوت تيليجرام يرسل الوظايف الجديدة كل صباح.
  • كل شي على GCP، مبني بـ Terraform، وينشر نفسه تلقائياً، وفيه مراقبة وتنبيهات.
  • ريبو على GitHub فيه رسم للنظام وشرح، وبوست LinkedIn.

شكل النظام

  Every day 08:00
  Cloud Scheduler ──▶ Collector (Cloud Run Job)
                          │  fetch: Greenhouse / Lever / Workable + manual programs
                          │  filter: drop roles asking 3+ years
                          ▼
                      Cloud SQL (Postgres) ◀── Web (Cloud Run Service)
                          │                     ├─ public jobs page
                          ▼                     └─ Telegram subscribe webhook
                    Telegram: send new jobs to subscribers

النظام فيه خدمتين بس: Collector وWeb. خدمة أقل يعني تعقيد أقل وأنت تتعلم.

طريقة كل جلسة

1. شرحوش المفهوم، وليش موجود، ومثال من الحياة، قبل أي كود.
2. تطبيقأنت تكتب الكود أو الأوامر بنفسك، وأنا معك.
3. تحققنكسر الشي عن قصد ونصلحه، أو تشرحه بكلامك. ما ننتقل قبل ما يكون واضح.

الوقت: ساعة ونص إلى ساعتين في اليوم، 5 أيام في الأسبوع، ويوم السبت مراجعة.
