الهدف النهائي

خدمة تجمع كل يوم وظايف التقنية للخريجين وبرامج تطوير الخريجين في السعودية، وتشيل اللي يطلب خبرة، وتنشر الجديد كل صباح في قناة تيليجرام وعلى صفحة ويب عامة.

بعد 4 أسابيع يكون عندك:

  • صفحة ويب عامة برابط حقيقي وHTTPS، تتحدث كل يوم.
  • قناة تيليجرام ينشر فيها البوت الوظايف الجديدة كل صباح.
  • كل شي على AWS، مبني بـ Terraform، وينشر نفسه تلقائياً، وفيه مراقبة وتنبيهات.
  • ريبو على GitHub فيه رسم للنظام وشرح، وبوست LinkedIn.

شكل النظام

  Every day 08:00 (Riyadh)
  EventBridge Scheduler ──▶ Collector (ECS Fargate task, runs ~2 min)
                               │  fetch: Greenhouse / Lever / Workable + manual programs
                               │  filter: drop roles asking 3+ years
                               ├──▶ RDS Postgres (private)    save jobs, find the new ones
                               ├──▶ S3 ──▶ CloudFront (HTTPS) public jobs page
                               └──▶ Telegram channel          post new jobs

النظام كله برنامج واحد يصحى كل صباح، يشتغل دقيقتين، ويطفي. يحفظ الوظايف في قاعدة البيانات، ويطبع صفحة الويب كملف جاهز، وينشر الجديد في القناة.

ليش ما فيه سيرفر ويب شغال طول اليوم؟ السيرفر اللي شغال 24 ساعة هو أغلى شي في AWS، ويحتاج خدمات شبكات مدفوعة. لما تكون الصفحة ملف جاهز، والناس تشترك في قناة بدل البوت، يصير الشي الوحيد اللي يكلف هو قاعدة البيانات. والتعلم نفسه ما ينقص.

طريقة كل جلسة

1. شرحوش المفهوم، وليش موجود، ومثال من الحياة، قبل أي كود. وكل مصطلح جديد ينشرح.
2. تطبيقأنت تكتب الكود أو الأوامر بنفسك، وأنا معك.
3. تحققنكسر الشي عن قصد ونصلحه، أو تشرحه بكلامك. ما ننتقل قبل ما يكون واضح.

الوقت: ساعة ونص إلى ساعتين في اليوم، 5 أيام في الأسبوع، ويوم السبت مراجعة.

الهدف: أمر واحد يشغّل النظام كامل على جهازك، بدون أي سحابة.

الأسبوع 2: CI وأول مرة على AWS

الهدف: المشروع شغّال على AWS، وأنت بنيته بيدك من الموقع.

ليش نبني يدوي أول؟ عشان تفهم كل قطعة بيدك. وفي الأسبوع الجاي بنحوّل نفس الخطوات لكود، وبتعرف بالضبط وش يسوي كل سطر.
✅ نهاية الأسبوع: رابط *.cloudfront.net شغّال على الإنترنت، وأي أحد يقدر يفتحه.

الأسبوع 3: كل شي كود، وكل شي تلقائي

الهدف: تحذف كل اللي سويته يدوي، وأمر واحد يرجّعه.

✅ نهاية الأسبوع: تحذف كل شي، وterraform apply يرجّع النظام كامل. وتعديل سطر واحد ينزل لحاله.

الأسبوع 4: مراقبة وإطلاق

الهدف: نظام تقدر تعتمد عليه، وناس تستخدمه.

✅ نهاية الأسبوع: مشروع منشور، وعليه مستخدمين، وريبو مرتب، وبوست على LinkedIn.

القاموس

Docker / image / container
الـ image صندوق جاهز فيه البرنامج وكل اللي يحتاجه. والـ container هو الصندوق وهو شغّال.
CI / CD
CI: الاختبارات تشتغل تلقائياً مع كل تعديل. CD: النشر يصير تلقائياً بعد الدمج.
IAM
نظام الصلاحيات في AWS: مين يقدر يسوي وش.
root
الحساب الأساسي في AWS، يقدر يسوي كل شي. نحميه وما نستخدمه.
VPC / subnet
شبكتك الخاصة داخل AWS. الـ subnet جزء منها: عام يوصل للإنترنت، أو خاص مخفي.
NAT Gateway
بوابة تخلي الجزء الخاص يطلع للإنترنت. تكلف حوالي 33 دولار في الشهر، فنتجنبها.
RDS
قاعدة بيانات Postgres تديرها AWS عنك: النسخ الاحتياطي والتحديثات عليهم.
ECR
مكتبة في AWS تحفظ فيها الـ images برقم إصدار.
ECS Fargate
يشغّل الصندوق حقك بدون ما تدير سيرفر. تدفع على الدقايق اللي اشتغلها بس.
EventBridge Scheduler
منبّه يشغّل البرنامج في وقت محدد كل يوم.
S3 / CloudFront
S3 مخزن ملفات. وCloudFront يوصلها للناس بسرعة وبرابط HTTPS.
SSM Parameter Store
خزنة في AWS للأسرار مثل التوكنات وكلمات المرور.
CloudWatch
المكان اللي تشوف فيه السجلات والأرقام، وتحط فيه التنبيهات.
Terraform / state
تكتب البنية كملفات وهو يبنيها. والـ state دفتر يتذكر فيه وش بنى.
OIDC
طريقة تخلي GitHub يدخل AWS بهوية مؤقتة، بدل مفتاح سري محفوظ.
AWS CLI
ريموت كنترول لـ AWS من التيرمنال.

وش ينضاف في سيرتك

Saudi Junior Jobs Radar — AWS · Terraform · Docker · GitHub Actions · Python · Postgres
  • Built a service that collects junior tech jobs and graduate programs in Saudi Arabia daily and posts them to a Telegram channel with [X] subscribers.
  • Provisioned all infrastructure with Terraform on AWS (ECS Fargate, RDS, EventBridge Scheduler, S3, CloudFront), with keyless OIDC CI/CD from GitHub Actions.
  • Designed for low cost (no always-on servers or NAT), with monitoring, alerting and one-step rollback; the pipeline scans every image before deploy.
